# MVA — دستیار نصب تلویزیون

نسخه 0.3 یک نمونه مستقل برای آزمایش مکالمه فارسی جهت دریافت درخواست نصب تلویزیون است. این پروژه مستقل از MTA است.

## اطلاعاتی که دریافت می‌شود
- نام و نام خانوادگی
- کد ملی
- تلفن ثابت و همراه، یا دو شماره همراه
- محصول (فعلاً فقط تلویزیون)
- شماره سریال
- نوع نصب: دیواری یا زمینی (روی پایه)

## قابلیت‌های فعلی
- رابط فارسی و راست‌چین، فرم بازبینی اطلاعات
- مکالمه مرحله‌ای کنترل‌شده با نگه‌داری موقت وضعیت نشست
- تشخیص گفتار فارسی در مرورگرهای پشتیبانی‌شده و ورود دستی
- اعتبارسنجی پایه اطلاعات
- ذخیره خروجی JSON محلی پس از تأیید
- endpoint اختیاری برای تست اتصال AI با پیام ثابت و غیرشخصی
- هیچ اتصال به مرکز تماس، SIP، کال‌سنتر یا سامانه بیرونی ندارد

**محدودیت مهم:** مکالمه فعلی نمونه مرحله‌ای است؛ هنوز از مدل AI برای مکالمه با مشتری استفاده نمی‌کند. خروجی JSON نیز ثبت رسمی درخواست نیست.

## اجرا در ویندوز
از داخل پوشه MVA:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
py -m pip install -r backend\requirements.txt
py -m uvicorn app.main:app --app-dir backend --reload --port 8011
```

سپس `http://127.0.0.1:8011` را باز کنید. سلامت API: `/api/health`؛ مستندات: `/docs`.

## تست اتصال AI
مسیرهای `/api/ai/status` و `/api/ai/test` برای بررسی پیکربندی و ارسال یک پیام ثابت و غیرشخصی هستند. اتصال به‌صورت پیش‌فرض خاموش است. متغیرهای نمونه در `.env.example` آمده‌اند؛ این فایل خودکار بارگذاری نمی‌شود. کلید واقعی را در Git قرار ندهید.

## حریم خصوصی
در تست فقط داده ساختگی وارد کنید. نشست‌ها در حافظه موقت سرور نگه‌داری و با راه‌اندازی مجدد پاک می‌شوند. فایل خروجی فقط داخل پوشه محلی `outputs` ذخیره می‌شود. تست اتصال AI اطلاعات مشتری را ارسال نمی‌کند. تشخیص گفتار مرورگر ممکن است از سرویس تشخیص گفتار خود مرورگر استفاده کند.
